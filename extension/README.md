# 코레일 목록 확인 — 읽기 전용 확장프로그램

정상적으로 조회되는 일반 Chrome에서 개발자 도구(F12)를 열지 않고 공개 열차 목록을 읽기 위한 첫 검증 버전입니다. 자동 조회·예약·결제·외부 전송 기능은 없습니다. 현재 Tkinter 설정창과는 별도로 실행합니다.

## 설치

1. **평소 쓰는 일반 Chrome** 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다. 이것은 확장프로그램 설치 설정이며 **F12 개발자 도구를 여는 동작이 아닙니다.**
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 아래 폴더를 선택합니다. 파일이 아닌 **extension 폴더**입니다.

```text
C:\Users\bill7\OneDrive\문서\ChatGPT\기차예매 매크로\extension
```

5. Chrome 우측 퍼즐 모양 아이콘에서 **코레일 목록 확인**을 고정합니다.

Chrome 공식 설치 안내: https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

## 확인

1. 정상 Chrome에서 코레일 열차를 직접 조회합니다.
2. 목록이 보이는 탭에서 **코레일 목록 확인** 아이콘을 누릅니다.
3. **현재 목록 읽기**를 누릅니다.
4. 날짜·구간과 07:47 / 08:20 항목 등이 표시되는지 확인합니다.
5. **진단 파일 저장**을 누르고 내려받은 `korail-public-snapshot-….json` 파일을 작업 대화에 첨부합니다. 팝업의 **저장할 내용 확인**에서 동일한 내용을 먼저 볼 수 있습니다.

시크릿 창에서 쓰려면 확장프로그램의 **세부정보 → 시크릿 모드에서 허용**을 켜야 합니다. 일반 창에서 정상 조회된다면 일반 창으로 확인하면 됩니다.

팝업을 닫으면 읽었던 내용은 사라집니다. 다시 열고 읽기 버튼을 누르면 됩니다. 코드를 업데이트한 경우 `chrome://extensions`에서 이 확장프로그램 카드의 새로고침 버튼을 누르세요.

## 읽는 범위

- `https://www.korail.com/ticket/search/list`의 공개 조회 조건과 `.tckWrap` 열차 결과 영역만 읽습니다.
- 페이지를 변경하거나 버튼을 누르지 않습니다. 현재 화면에 로드된 항목만 읽으며 더보기도 자동으로 누르지 않습니다.
- 쿠키, 저장된 로그인 정보, 숨겨진 입력값, 결제 화면, 요청/응답은 읽지 않습니다.
- 진단 파일에는 공개 텍스트와 제한된 구조(태그·클래스명)가 들어갑니다. URL의 query, DOM ID, data 속성, 이벤트 핸들러는 제외합니다.
- 모든 데이터는 팝업 메모리에 있으며, 저장 버튼을 누를 때만 JSON 파일로 내려받습니다.

권한은 `activeTab`과 `scripting`만 사용합니다. 상시 사이트 접근, debugger, 네트워크 감시, 백그라운드 실행 권한은 없습니다.

## 현재 검증 범위

모의 공개 DOM에서 정보 추출·숨김 정보 제외·다른 페이지 거절·팝업 표시·JSON 다운로드를 검증합니다. 실제 코레일 화면에서 이 확장프로그램으로 목록을 읽을 수 있는지는 사용자의 설치 후 확인이 필요합니다. 읽기에 성공하더라도 반복 조회·예약·결제가 성공한다는 의미는 아닙니다.
